Questions

Will Raftaar increase my FPS?

It depends on your PC. On machines with lots of background load the difference can be large; on a clean, powerful PC it can be small. That is why Raftaar includes an FPS Test: measure before, optimize, measure after, and see the real change.

Windows says "Windows protected your PC". Is it safe?

That SmartScreen message appears for new apps without a paid code-signing certificate yet. Click "More info", then "Run anyway". The source code is public on GitHub, and every update is cryptographically signed.

Why does it need administrator rights?

Some settings (power, game scheduling, restore points) live in system-wide parts of Windows. Raftaar only changes the settings listed in the app.

How do I undo everything?

Click "Revert all" in the sidebar. Raftaar puts back every value it saved. You can also use the restore point it created.

Does Raftaar collect my data?

No. It works offline. The only network request is checking GitHub for updates (and, for card licenses, checking the license).
